02 / 05

Context

What it is

B24 Sales Analyst is a private read-only agent that synchronizes Bitrix24 deals, builds verifiable day/week/month metrics and delivers a concise explanation to a manager in Telegram.

The problem it solves

Manual reporting consumes time, while an “AI analyst” that calculates from prose creates a new risk: polished explanations cannot be reconciled with the CRM or separated from hallucination.

03 / 05

System

Technical stack

PythonBitrix24 APISQLiteSQLTelegrampytest

Architecture

A read-only Bitrix24 adapter stores a normalized snapshot in SQLite. The SQL layer computes metrics and control totals, reconciliation compares them with the CRM, and only then does the LLM receive an immutable JSON facts payload with no calculation access.

Why this architecture

Separating calculation from explanation makes a report reproducible. Numbers survive an unavailable model, and every disputed statement can be traced to a deterministic query and source snapshot.

Evidence

Strengths

The LLM is deliberately denied the role of calculation system. It improves the readability of a proven result, while read-only integration, reconciliation and masked logs reduce the blast radius.

What it proves

The case demonstrates a mature AI boundary: API integration, a data pipeline, SQL modelling, observability, safe delivery and the discipline not to use an LLM where exactness is required.

Quality · QA

How quality was engineered

Eighty tests cover synchronization, pagination, mapping, SQL metrics, periods, re-import, CRM reconciliation, LLM degradation and masking. Secrets and personal fields never enter logs or public fixtures.
