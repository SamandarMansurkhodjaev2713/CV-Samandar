Kontekst

Bu nima

Telegram Sheets Task Bot — xodimlar Telegram’da vazifa olib o‘zgartiradigan, Google Sheets esa yagona persistent store bo‘lib qoladigan private task-workflow. U boshqariladigan status, yangi task, reminder, report hamda text yoki voice’ni tasdiq bilan talqin qilishni qo‘llaydi.

Qanday muammoni yechadi

Jadval biznes uchun qulay, ammo o‘zi application transaction bermaydi. Parallel update ajralishi, eski callback eskirgan transition’ni qo‘llashi, AI ruxsatsiz task’ni tanlashi, delivery xatosi esa o‘zgargan satrni xabar va audit’siz qoldirishi mumkin.

Texnik stek

Arxitektura

Apps Script V8 Telegram update’larni polling orqali oladi. Har bir action telegram_id va domain permission’ni qayta tekshiradi. Callback HMAC va task/session versiyasini olib yuradi; application layer transaction plan tuzadi, Sheets batchUpdate esa task, audit, idempotency marker, outbox, session va Telegram offset’ni atomar saqlaydi. Alohida dispatcher outbox’ni chegaralangan retry bilan yetkazadi.

Nega aynan shunday

Dizayn Sheets’ni odatiy baza deb ko‘rsatmay, ongli cheklov sifatida qabul qiladi. Toza TypeScript-domain transaction plan’ni tuzadi va keyin bitta batch qo‘llanadi; offset effect bilan birga commit bo‘ladi, shu sabab takroriy update xavfsiz taniladi yoki operatsiya to‘liq yakunlanadi.

Kuchli tomonlari

Alohida serversiz ham asosiy operational risk’lar yopilgan: signed stale-action guard, atomic multi-range write, durable outbox, chegaralangan retry’dan keyin dead-letter, protected column va AI chaqiruvidan oldin budget reservation. Bu nimani isbotlaydi

Keys qat’iy byudjet va platforma cheklovida system thinking’ni ko‘rsatadi: auth, state machine, integrity, transaction design, AI guardrail, speech integration, operations va traceable QA bitta qo‘llab-quvvatlanadigan mahsulotga yig‘ilgan.
