Context

What it is

DentForma is a private browser-based workflow for reviewing 3D shape. A technician creates a case and uploads models, an assigned participant expresses a bounded change in an approachable editor, and completion records a separate immutable revision for further professional work.

The problem it solves

Words, arrows on screenshots and voice notes communicate spatial change poorly. Versions become mixed, and it is unclear which model was the reference, who changed the shape and which result was actually approved.

Architecture

The React/Vite UI is separated from an imperative Three.js editor core. STL parsing and heavy geometry run in a Web Worker; typed contracts connect the UI to a NestJS/Fastify API. PostgreSQL stores cases and revisions, private S3/MinIO stores models, and a transactional outbox delivers notifications. The reference stays immutable while the editable mesh changes deterministically.

Why this architecture

The product deliberately avoids becoming browser CAD. Role boundaries and a short operation set reduce error cost, the worker keeps mesh processing off the interface thread, and immutable submit separates exploration from the result handed back to the technician.

Evidence

Strengths

The strength is not WebGL alone but the accountable workflow around geometry: file preflight, semantic slots, scoped access, optimistic concurrency, private draft, confirmation and reproducible export. The participant sees only actions required for review.

What it proves

The case proves the ability to deliver a difficult product across 3D, full-stack, security and UX — from domain constraints and mesh lifecycle to private storage, operational runbooks and a verifiable release process.

Quality · QA

How quality was engineered

Unit and integration tests cover mesh IO, editor invariants, auth, quotas, outbox and contracts. Playwright covers roles, editor flows, retries, concurrency and a security matrix; synthetic geometry keeps client STL out of test artifacts. WebGL context restore, reduced motion and the mobile fallback are verified separately.
