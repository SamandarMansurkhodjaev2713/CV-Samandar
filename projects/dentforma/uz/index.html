Kontekst

Bu nima

DentForma — 3D shaklni kelishish uchun private browser-based workflow. Texnik keys yaratib modellarni yuklaydi, tayinlangan ishtirokchi tushunarli editorda chegaralangan o‘zgarishni ko‘rsatadi, yakun esa keyingi professional ish uchun alohida o‘zgarmas revision’ni qayd etadi.

Qanday muammoni yechadi

So‘z, screenshot’dagi strelka va voice note fazoviy o‘zgarishni yomon yetkazadi. Versiyalar aralashadi, qaysi model reference bo‘lgani, shaklni kim o‘zgartirgani va qaysi natija tasdiqlangani noaniq qoladi.

Tizim

Texnik stek

ReactTypeScriptThree.jsWeb WorkerNestJSPostgreSQLPrismaS3Playwright

Arxitektura

React/Vite UI imperative Three.js editor core’dan ajratilgan. STL parsing va og‘ir geometriya Web Worker’da ishlaydi; typed contracts UI’ni NestJS/Fastify API bilan bog‘laydi. PostgreSQL keys va revision’larni, private S3/MinIO modellarni saqlaydi, transactional outbox xabar yetkazadi. Reference o‘zgarmaydi, editable mesh esa deterministik o‘zgaradi.

Nega aynan shunday

Mahsulot ataylab browser CAD’ga aylantirilmagan. Rol chegarasi va qisqa action to‘plami xato narxini kamaytiradi, worker mesh-processing’ni interface thread’dan chiqaradi, immutable submit esa draft izlanishni texnik oladigan natijadan ajratadi.

Dalillar

Kuchli tomonlari

Kuch faqat WebGL’da emas, geometriya atrofidagi mas’uliyatli workflow’da: file preflight, semantic slot, scoped access, optimistic concurrency, private draft, tasdiq va qayta olinadigan export. Ishtirokchi faqat kelishuv uchun kerakli action’larni ko‘radi.

Bu nimani isbotlaydi

Keys 3D, full-stack, security va UX kesishmasidagi murakkab mahsulotni yetkazish qobiliyatini ko‘rsatadi — domain cheklovi va mesh lifecycle’dan private storage, operational runbook va tekshiriladigan release’gacha.

Quality · QA

Sifat qanday ta'minlangan

Unit va integration testlar mesh IO, editor invariantlari, auth, quota, outbox va contract’larni qoplaydi. Playwright rollar, editor, retry, concurrency va security matrix’ni tekshiradi; synthetic geometry client STL’ni test artifact’dan chiqaradi. WebGL context restore, reduced motion va mobile fallback alohida tekshiriladi.
