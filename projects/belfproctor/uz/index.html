Kontekst

Bu nima

Yopiq proctoring/monitoring tizimi: Windows client-agent, backend ingestion API va hodisalar, statuslar hamda tekshiruv materiallarini ko'rish uchun admin-panel.

Qanday muammoni yechadi

Proctoring shunchaki veb-forma bo'la olmaydi. O'rnatiladigan mijoz, heartbeat, hodisalarni yig'ish, himoyalangan uzatish, retry-mantiq, monitoring siyosati, admin-ko'rinish va aniq tekshiruv workflow kerak.
