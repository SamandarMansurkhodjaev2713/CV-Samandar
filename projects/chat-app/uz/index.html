Kontekst

Bu nima

ChAT — beqaror tarmoq atrofida loyihalangan ochiq React Native messenger prototipi: durable lokal outbox, dubldan himoyalangan qayta yetkazish, realtime sync va tekshiriladigan Firebase access rules.

Qanday muammoni yechadi

Happy-path chat «yuborish» bosilishi va server tasdig‘i orasida aloqa uzilmaguncha oddiy ko‘rinadi. Shunda xabar yo‘qolishi, takrorlanishi yoki noto‘g‘ri statusda qolishi, zaif security rules esa begona ma’lumotni ochishi mumkin.

Tizim

Texnik stek

React NativeExpoTypeScriptFirebaseSQLiteJest

Arxitektura

Feature-modullar domain va adapterlarni ajratadi. SQLite durable outbox’ni saqlaydi, har xabarda barqaror idempotency key bor, sync worker bounded backoff ishlatadi, Firebase services esa auth, realtime, media va server-side OTP’ni beradi. ESLint arxitektura chegarasini chetlab o‘tishni taqiqlaydi.

Nega aynan shunday

Local-first state UI’ni halol qiladi: pending, failed va delivered — optimistic bezak emas, real holatlar. Idempotency qayta yetkazishni qayta yaratishdan ajratadi, security rules production backend’dan oldin emulator’da testlanadi.
