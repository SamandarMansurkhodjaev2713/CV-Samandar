02 / 05

Context

What it is

Vacation Control Agent is a private Telegram tool for HR operations. It reads an approved leave schedule, prepares the document, drives sequential confirmation and persists unfinished work across restarts.

The problem it solves

The manual process lives in a spreadsheet, an order template, chat messages and one employee's memory. A confirmation can be missed, a notification duplicated or an open case lost after failure.

Architecture

Import is separated from the workflow core: an Excel adapter normalizes records, a document service creates the Word file, a state machine owns the sequence, SQLite stores state and idempotency keys, and Telegram only transports commands and confirmations.

Why this architecture

A deterministic core makes replay safe: a restart does not begin the leave process again, and a network retry cannot create a second document or message. The spreadsheet format and delivery channel can change without rewriting the business sequence.

Evidence

Strengths

The value is not merely generating a file; it is controlling an unfinished process. The agent knows which step is confirmed, what is expected next and why a repeated event cannot be applied twice.

What it proves

The case demonstrates end-to-end operational ownership: familiar office formats, state machines, document automation, Telegram UX, recovery and privacy-first public communication.

Quality · QA

How quality was engineered

Seventy-two tests cover schedule parsing, state transitions, document generation, redelivery, deduplication and restart recovery. Adapter boundaries let the workflow run without real Telegram or personal data.
